# ASH 5.1 Explorer

Single-file interactive explorer for the Adaptive Strategy Hypothesis 4.6.

## What it does
- Parameter-driven scenario simulator
- Ranked strategies and actors (NHI, AGI, Human Institutions)
- Intelligence brief with Copy and Export
- Pure-CSS tab navigation (works when the file is shared and opened on phones)
- Embedded protocol outputs (Delta / Complete)

## How to use
1. Open `index.html` (or the HTML file) in Safari or Chrome.
2. Use the tabs to move between sections.
3. On the Simulator tab, adjust the sliders and tap **Update**.
4. Tap **Protocol Complete** for the full synthesis.
5. Use **Copy Brief** or the Export Record for a plain-text snapshot.

## Sharing
The file is self-contained. Pure-CSS tabs mean navigation works under `file://` on most phones. For a stable link, this repository is configured for GitHub Pages.

## Model
ASH 5.1 is a non-anthropocentric framing of the Fermi silence via dominant hiding, a tiered Sphere Network, and a mixed ESS that now includes AGI and government institutions as distinct actors. Claims in the protocol outputs are labeled.
